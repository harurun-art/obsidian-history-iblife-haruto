| ----------- | --------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ----------- |
| **内政・社会**   | 「[[アメとムチ]]」の政策。[[文化闘争]]や[[社会主義者鎮圧法]]で反体制派を弾圧（ムチ）する一方、[[社会保険制度]]で労働者を保護（アメ）。 | 皇帝の個人的な独裁傾向が強まる。人口が急増し、1913年には約6700万人に達する。                                         |             |
| **外交・国際関係** | [[ビスマルク体制]]。[[フランス]]の孤立化と[[二正面作戦]]の回避を優先し、ヨーロッパ内の勢力均衡（現状維持）を図る。             | [[世界政策]]（帝国主義的膨張）。強硬な外交で[[イギリス]]や[[ロシア]]と対立し、逆に[[三国協商]]による包囲網を作られてしまう。             |             |
| **経済・産業**   | 1879年の[[保護関税法]]により、国内の地主（[[ユンカー]]）の農業と資本家の重工業を保護。工業化（[[第2次産業革命]]）の基盤が作られる。  | ヨーロッパ最大の工業国へと成長。石炭生産量が激増し、1913年の鉄鋼生産量は[[イギリス]]の約2倍に達した（独：**約1760万トン、英：約770万トン** ）。 |             |
| **軍事・戦略**   | 圧倒的な陸軍力を背景に、大陸内での抑止力維持に注力。海軍の大規模な拡張は控えていた。                                  | 海軍の急拡大（[[建艦競争]]）により[[イギリス]]の覇権に挑戦。対仏露の挟み撃ちを想定した[[シュリーフェン・プラン]]を策定。                 |             |
