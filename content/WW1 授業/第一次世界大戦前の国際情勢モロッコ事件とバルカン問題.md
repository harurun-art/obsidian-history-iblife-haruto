#世界史 #第一次世界大戦 #モロッコ事件 #東方問題

## 1. [[モロッコ事件]]（1905年〜）：[[英仏協商]]の結束と[[ドイツ]]の誤算

[[ドイツ]]は、急接近した[[イギリス]]と[[フランス]]の結びつき（[[英仏協商]]）が「本物かどうか」を試すために、[[フランス]]が狙っていた[[モロッコ]]にちょっかいを出した（[[第一次モロッコ事件]] / [[タンジール事件]]）。

### 各国の思惑と結果

| **国**        | **当時の状況・思惑**                                                                          | **結果・行動**                                                       |
| ------------ | ------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| **[[イギリス]]** | 【[[英仏協商]]】「[[イギリス]]の[[エジプト]]支配を認める代わりに、[[フランス]]の[[モロッコ]]支配を認める」という約束を[[フランス]]と交わしていた。 | 約束通り、[[フランス]]を強力にバックアップした。[[ドイツ]]の介入を退ける。                       |
| **[[フランス]]** | [[イギリス]]の支援を背景に、[[モロッコ]]を自国の支配下に置きたい。                                                 | [[イギリス]]の支援を得て強気に出る。                                            |
| **[[ドイツ]]**  | 英仏の分断を狙って介入。「なんだかんだで[[モロッコ]]をもらえるか、英仏が譲歩するだろう」と期待していた。                                | 目論見は完全に外れた。ただし、話し合い（[[アルヘシラス会議]]）の場は持ち、外交的解決は図ろうとした。            |
| **[[ロシア]]**  | [[日露戦争]]（1904-05年）で敗北し、国力がボロボロの状態だった。                                                 | [[ドイツ]]から「強国の[[ロシア]]も今なら動けないだろう」と見くびられ、[[ドイツ]]介入のタイミングを作ってしまった。 |

> [!info] 補足：歴史の歯車
> 
> [[ドイツ]]は孤立こそしなかったものの、結果的に英仏の「互いを尊重し助け合う関係」をより強固なものにしてしまった。この事件をきっかけに、[[ヨーロッパ]]の緊張はさらに高まっていく (中山, 1990)。

## 2. [[バルカン問題]]（[[東方問題]]）：火薬庫への点火

アフリカでの対立の次は、[[ヨーロッパ]]の端「[[バルカン半島]]」で問題が激化する。弱体化した[[オスマン帝国]]（[[トルコ]]）が手放した領土の空白地帯へ、[[ロシア]]や[[オーストリア]]が進出しようとして生じた一連の国際摩擦を**[[東方問題]]**と呼ぶ。

### [[ベルリン会議]]（1878年）以降の各国の状況と思惑

1908年の大きな転換点（[[青年トルコ革命]]など）を迎える前の、各国の基本設定は以下の通り。

| **国・地域**                           | **当時の状況と抱えていた事情**                                 | **バルカン半島における思惑・目標**                                               |
| ---------------------------------- | ------------------------------------------------- | ----------------------------------------------------------------- |
| **[[オスマン帝国]]（[[トルコ]]）**            | 国力が著しく衰退しており、[[バルカン半島]]に持っていた広大な領土を次々と喪失している状態。   | これ以上の衰退を防ぎたいが、独立運動や列強の介入を止められない。                                  |
| **[[セルビア]]**                       | すでに独立を達成している。気性が荒く、民族意識が高い。                       | かつての大帝国復活を夢見る。[[オーストリア]]内に散らばる同民族と合流し、「[[南スラヴ王国]]」を形成したい。         |
| **[[ロシア]]**                        | [[日露戦争]]の敗北で痛手を負っているが、スラヴ民族の擁護者を自負している。           | 新しくできた弱い国々（[[セルビア]]等）を守る立場にある。また、悲願である「[[南下政策]]」を狙っているが何度も失敗している。 |
| **[[オーストリア]]（[[オーストリア＝ハンガリー帝国]]）** | 非常に多くの民族を抱える[[多民族国家]]。国内の統制が難しい。                  | [[ベルリン会議]]で「[[ボスニア・ヘルツェゴビナ]]」の管理（支配）権を獲得。南下してくる[[ロシア]]と激しく対立する。   |
| **[[ブルガリア]]**                      | [[オスマン帝国]]の一部ではあるが、「[[自治公国]]」として実質的な自治が認められている状態。 | （※後の1908年に完全な独立を宣言することになる）。                                       |
| **[[モンテネグロ]]**                     | [[セルビア]]同様、すでに独立を達成している国。                         | [[ロシア]]の後ろ盾を頼りにしている。                                              |

> [!note] 史実チェック：対立の構図
> 
> [[バルカン半島]]は、ゲルマン系（[[オーストリア]]・[[ドイツ]]）の**[[パン＝ゲルマン主義]]**と、スラヴ系（[[ロシア]]・[[セルビア]]）の**[[パン＝スラブ主義]]**が真っ向から衝突する場所となった。この複雑な民族・領土問題が、後に「[[ヨーロッパの火薬庫]]」と呼ばれるゆえんである (柴, 2015)。
