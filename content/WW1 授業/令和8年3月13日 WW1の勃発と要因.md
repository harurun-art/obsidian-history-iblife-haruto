# 2. WW1の要因分析
戦争が起きた原因は単一の出来事だけではなく、長期的に蓄積された様々な要因が絡み合っている。

大テーマ：バルカン半島の緊張

| 要因の分類   | 概要と具体例                                 | 備考・追記メモ                                    |
| ------- | -------------------------------------- | ------------------------------------------ |
| 経済的要因   | オスマントルコ帝国の近代化の失敗                       | 工業化の遅れなど。<br>これが、バルカン半島の各国のナショナリズムの高まりを助長。 |
| イデオロギー的 | オスマン帝国の衰退→バルカン半島の各国のナショナリズムの高まり。       | 特にセルビア                                     |
| 領土的     | マケドニアやアルバニア、ボスニアを巡った緊張の高まり             | ボスニア危機やバルカン戦争など                            |
| 政治的     | 各国での国内の不満や危機をバルカン半島における外交的勝利で覆い隠そうとした。 | オーストリア、ロシアなど                               |
